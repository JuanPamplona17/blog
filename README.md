# Blog personal 

Blog personal creado con HTML, CSS y JavaScript vanilla.

## Caracteristicas

- Diseño responsive (móvil, escritorio)
- Tema claro/oscuro
- Navegación adaptable con menú hamburguesa en móvil
- iconos svg inline con soporte para cambio de tema

## Estructura

```
├── index.html          # Archivo principal
├── css/
│   ├── main.css        # Estilos principales
│   ├── variables.css   # Variables CSS (colores, fuentes)
│   ├── reset.css       # Reset de estilos
│   └── components.css  # Componentes reutilizables
└── js/
    ├── main.js         # Inicialización
    ├── theme.js        # Cambio de tema
    ├── posts.js        # Gestión de posts
    └── mobile-menu.js  # Menú móvil

```

## Uso

`python3 -m http.server 8000`
